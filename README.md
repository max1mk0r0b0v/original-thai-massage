# Original Thai Massage Jerusalem

A static Hebrew-first local business website for Original Thai Massage Jerusalem.

## Included

- TypeScript + Tailwind CSS
- Modular App Router structure
- Central business config in `content/site-config.ts`
- Reusable content datasets in `content/services.ts`, `content/faq.ts`, and `content/testimonials.ts`
- Aggregated content export in `content/site.ts`
- Hero, Services, Gallery, Reviews, Contact, Opening Hours, and Footer sections
- Static contact CTAs for phone and WhatsApp

## Quick start

```bash
npm install
npm run dev
```

## Environment

No environment variables are required.

## Reuse

1. Update `content/site-config.ts` with the new business name, tagline, colors, contact details, and booking links.
2. Replace the arrays in `content/services.ts`, `content/faq.ts`, and `content/testimonials.ts`.
3. Adjust any section copy in `content/site-config.ts`.
